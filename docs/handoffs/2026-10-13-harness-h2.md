## What changed

`uv run e-agent-harness <cmd>` now exists with nine commands over the H1 state:

| Command | Role in the session loop |
|---|---|
| `validate-context` | manifest vs checkout, plus "roadmap links the active plan" |
| `new-task <phase> <id> --feature … --paths …` | materialises a task contract (digest, base commit, allowed paths incl. `harness/state/**`, `docs/handoffs/**`, the active plan) and makes it active |
| `check-scope [--hook]` | tree check since the task's base commit; as a `PreToolUse` hook it judges one `Edit`/`Write`/`NotebookEdit` path, resolved from the payload's `cwd`, exit 2 denies |
| `gate <set> [--package] [--timeout] [--keep-going]` | runs the manifest's gate set, writes `evidence/gates/<task>/<ts>.json` with commit SHA, clean-tree flag, exit codes, counts, redacted output tails |
| `live-check` | the `live` gate set, redacted, under `evidence/live/` |
| `checkpoint [--hook]` | appends a progress entry (session, task, changed files, next); `PreCompact` mode never fails |
| `handoff <id>` | validates the handoff document and its evidence refs |
| `close-check [--session] [--hook]` | clean tree, progress entry for this task/session, every `passes: true` tied to evidence on HEAD (or an ancestor with only bookkeeping after it), handoff valid; `Stop` mode inert unless `E_AGENT_HARNESS_UNATTENDED=1` |
| `status [--format text\|hook]` | the brief: Vietnamese ELI5 first, then English; hook format is SessionStart JSON within the manifest's token budget |

Modules: `cli`, `state`, `gitinfo`, `tasks`, `scope`, `gate`, `closecheck`, `status` under `tools/harness/src/e_agent_harness/`; new schema `gate-evidence`; tests under `tests/harness/` (50) on a scratch git repository fixture.

## Rulings

- `live-check` runs the `live` gate set with redaction; the live flows wait for the H5 pilot. Cost if wrong: one command extension.
- Close-ritual order is commit → `gate` on the clean tree → checkpoint, handoff, bookkeeping commit. Evidence from a dirty tree is rejected. Cost if wrong: one extra gate run per task.
- Implicit allowed paths are written into the contract. Cost if wrong: none.
- "Plan updated if acceptance changed" is not code-checked; `--replace` makes it visible in git. Cost if wrong: a diverged plan found at review instead of at close.
- The Task 3 commit was made with three failing tests because a pipe to `tail` hid pytest's exit code; the cause (stripped `git status --porcelain` output) was fixed in `4c2c5f8` with a regression test, and gates ran with `pipefail` from then on. Cost: one extra commit.
- The redaction test's secret was changed from `abc` to `sk-live-ZZ987`: a 40-hex commit SHA can contain `abc`. Cost if wrong: none.

## Deferred minors

- `format: date-time` (task `created_at`, progress `timestamp`, evidence `started_at`) is still annotation-only; the CLI generates these values itself.
- Hook modes read the repository from the payload's `cwd` only when `--repo` is absent; H4 wires the hooks without `--repo`.
