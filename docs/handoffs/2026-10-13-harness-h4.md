### What bash-guard is not

`bash-guard` stops the commands an agent writes by habit. It is not a sandbox: it cannot see inside a script (`./deploy.sh`, a Python `subprocess` call) and cannot decode deliberate obfuscation. Round 5 listed the script case as informational under this model. An unattended run needs a real boundary: Claude Code's sandbox, or a container without the Docker socket and without push credentials, with branch protection on the remote. The owner is asked to accept this framing before the merge.
