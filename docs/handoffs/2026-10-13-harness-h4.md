## Rulings

- Phase `H4` ran through the harness; switching the active plan made the closed `1.R1` contract stale, so `new-task H4.1` needed `--replace`. Cost if wrong: none; `1.R1` had closed at `2c44691`.
- `git push`, `merge`, `rebase` and `reset --hard` are ask rules, not deny rules, so an owner-instructed merge still works. Cost if wrong: an approval prompt can be accepted by mistake.
- A closed task no longer limits unrelated edits through the hook; without this, every session in the checkout would be held to the last task's scope. Cost if wrong: work after a closed task is not scope-checked until the next `new-task` (protected paths still are).
- The reviewer subagent returns its JSON and the caller writes it, so the reviewer keeps no write tools. Cost if wrong: one extra step.
- User-specific allow rules stay in `.claude/settings.local.json`. Cost if wrong: none.
