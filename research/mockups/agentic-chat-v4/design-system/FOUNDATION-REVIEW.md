Scope: all current study-04 design work—research application, identity, tokens, generated assets, 32 catalog entries, shared interactions, full chat/workspace composition, responsive behavior, embedding assumptions and the production adoption guide. ## Existing work retained and reviewed

The supplied source audit informs the warm visual direction, progressive disclosure and structured review alongside chat; no exact visual copying or usability-validation claim is made. The prior component/Claude review and its corrections remain recorded separately.

The full mockup retains collapsed navigation, a closable right workspace, per-thread drafts and sources, keyboard tabs, exact separate confirmations, stale approval rejection and unknown-outcome investigation without blind resend. The catalog retains named controls, field validation, source search, status distinctions, measured progress, disclosure, table scrolling and modal focus behavior. All examples are fictional and no model, credential, live business-data or write path was added.

The production code inspection confirms the correct adoption seam: existing tokens/components/layouts, layout-owned available-size observation, shared controller/hooks, and an existing Shadow DOM custom element. No new package/framework/state store is justified. Candidate styles are not yet consumed by that production custom element.

## Checks

- Token build/check: 99 tokens × three themes; alias/type errors, generated drift, text/status/destructive-action contrast, control/focus boundaries and token references across six authored design stylesheets.
- SVG export drift: 46 icons plus connected graph identity assets. Inline mark/wordmark and exported lockups share source geometry.
- Existing component/responsive and full chat suites: pass after the logo/theme/control changes.
- Embedded foundation: Chromium and WebKit pass host isolation, shadow-host themes, independent instances, container widths, retained drafts, close/reopen focus, modal focus/Escape, phone/tablet/short landscape, enlarged text, long Vietnamese copy/unbroken identifiers, and forced-colors/reduced-motion emulation.
- Visual evidence: `../screenshots/foundation/chromium/` and `../screenshots/foundation/webkit/`. The first pre-engine-folder capture is historical and may show the color-transition issue; engine-specific folders are regenerated after the fix.

This covers browser engines and simulated viewport/input conditions, not physical devices or screen-reader conformance. The enlarged-text case changes all public type-size tokens; it is not a claim that browser zoom or every assistive text preference was tested. The full standalone prototype remains document-responsive; container behavior is proven by the embedded specimen, not a claim that every standalone flow has been ported to Shadow DOM. The actual production element, backend authorization and live integrations remain outside this change.

## Independent review

[Claude’s focused review](CLAUDE-FOUNDATION-REVIEW.md) found additional portability/focus/feedback gaps. The [resolution](CLAUDE-FOUNDATION-RESOLUTION.md) records corrections, intentional design choices and the limits of that read-only critique. These include visible artifact focus at both compact and split widths, visible confirmation feedback, stronger inherited-style isolation, portable hidden hosts, import-graph bundling, token-checked container thresholds and enlargement of the complete type scale. Full-screen mobile focus and short-landscape composer visibility now have explicit checks.

The subsequent color revision replaces navy/cream with charcoal/warm white as a working default, with matching dark/high-contrast accents. The header symbol is now unboxed. A three-direction comparison uses shared components and contrast-checked role overrides. The launcher isolation check reads the generated accent token instead of hard-coding the previous brand color.
