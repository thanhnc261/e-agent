## Synthesis for the next visual pass

1. Center the interface on a task, its artifact and one clear next action. Use disclosure for sources/history, while keeping review scope, blockers and uncertainty immediately visible.
2. Build a small shared component family: task row, status label, artifact card, review card, source disclosure and recovery notice. Use a coherent line-icon set, consistent sizes/strokes, and text labels where meaning matters.
3. Keep three distinct meanings legible: the agent is working, a person must decide, and an outcome has been verified. Never collapse an unknown write outcome into failure or success.
4. Apply the user's warm neutral background, restrained navy primary action and simple logo as design direction. Reserve muted semantic colors for actual states. These visual choices are **not claims about the reference site's inspected appearance**; text extraction cannot establish its palette or typography.
5. Avoid adding a full control-room dashboard, numerical confidence meter, nested reasoning display, or automatic approval merely to demonstrate a pattern. Select only the elements that make the current workflow easier to understand and control.

This audit establishes source coverage and design rationale only. It does not establish live product behavior, usability results, accessibility conformance or release qualification.
